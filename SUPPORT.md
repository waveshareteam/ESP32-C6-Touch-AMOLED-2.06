# Support

For setup instructions, downloads, and board-specific guidance, start with the
[Waveshare product wiki](https://www.waveshare.com/wiki/ESP32-C6-Touch-AMOLED-2.06).

Before opening an issue:

1. Identify the exact example and framework version.
2. Confirm the board is ESP32-C6-Touch-AMOLED-2.06 and note its hardware revision.
3. Check the relevant GitHub Actions workflow for the same source revision.
4. Reproduce with the documented board options and bundled libraries.
5. Capture the complete serial log from reset through the failure.

Use a GitHub issue for reproducible source, build, documentation, or example defects.
Include expected behavior, actual behavior, reproduction steps, framework version,
board revision, and logs. Remove credentials, tokens, Wi-Fi passwords, serial numbers,
order details, and other private information.

For purchasing, warranty, replacement, or order-specific support, use Waveshare's
official support channel rather than a public repository issue.

Security vulnerabilities must not be filed as public issues; follow
[SECURITY.md](SECURITY.md).
